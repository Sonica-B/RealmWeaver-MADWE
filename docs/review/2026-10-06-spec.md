## Scope creep

- `realmweaver/cli.py` — `serve --biome`, `train-lora --out` are not in Task 8; `generate` prints `latency_s`/`tileability`, though the plan says the CLI prints no number outside a report.
- `realmweaver/config.py` — extra `models_dir`, `asset_size` settings.
- `realmweaver/world/scheduler.py` — `HORIZON=2` silently drops far pending requests; `abort`, `__contains__`, `pending`, per-call `cost_s`.
- `realmweaver/assets/pool.py` — CUDA-graph capture of the UNet step (`CapturedStep`) far exceeds "static buffers + optional torch.compile"; justified by `docs/research/05`, but unasked.
- `realmweaver/assets/diffusion.py` `_WHITE_BIAS` — latent mixing toward white; spec only says "generated on a white background".
- `realmweaver/assets/lora.py` — captions mined from file names, mirror augmentation, `train_log.json` (plan: caption = `build_prompt`).
- `world.py` `stats()`, `graph.py` (`seam_violations`, `count`, `best_asset`, `remove_chunk`), `types.py` (`DIR_NAMES`, `opposite`, `Asset.nbytes`, `Chunk.key`) — surface beyond the plan's interface lists.
- `unity/.../PlayerReporter.cs` is not in Task 6's file list; `TileCatalog` variant hashing and `fallback` exceed "tile class → prefab".
- `pyproject.toml` — `scipy` declared, imported nowhere.

- Further Notes "3.09 GB peak VRAM … must not regress" → `reports/bench-20261006-040554.json` `peak_allocated_gb` 3.14 (3.13 at n=20) — marginally above the floor; `docs/research/05` measured 3.04 in isolation. Needs a README caveat.

Benign today (client acts on `type`/`chunk` only), but the contract diverges; Task 5 must emit the list form.
- Allocator A/B → `realmweaver/metrics/bench.py` — the pool-off arm runs with the pool-on pipeline resident, so its `max_memory_allocated` (5.81 GB) is not a pool-off peak (noted in `notes`, still misleading).
